## G-003 feature proposal: Microphone / Real Piano input

Status: **💡 Idea — not implemented or shipped**.

Add an input mode to Play That Note!, alongside the existing Touch / On-screen Keyboard mode. Both use the same staff questions and answer interface. Listen through a phone/iPad microphone to a real piano; advance on correct pitch and retain the current question on a wrong pitch. Recognized-note and pitch-difference display are possible feedback. Detection accuracy, latency, permissions, and device behavior still need design and validation.

G-008 is the historical origin of this feature, not another development slot.
