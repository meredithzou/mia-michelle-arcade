# Little Doctor Clinic

A single-player, touch-friendly pretend clinic. Help Bunny, Panda, Fox, Kitten,
and Bear by listening to their story, choosing a checkup tool, and picking the
matching care. Celebrate with a sticker or a high five, then meet the next
patient. The five patients repeat, and the helped counter lasts for this visit.

This keeps the original Little Doctor Clinic prototype’s cases and gameplay.
It uses the shared Arcade return button and aggregate analytics. There are no
adjustable settings, saved progress, microphone access, or external assets.

## Play

Open `index.html` through the Arcade’s static server. Tap a checkup tool,
then a treatment. A different choice gives a gentle hint and can be retried.
After care, tap **Next patient** to continue.

`game.js` contains the patient cases and progression; `style.css` contains the
responsive clinic layout. The game uses system emoji and works without a
keyboard. This is pretend play, not medical instruction.
