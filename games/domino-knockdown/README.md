# Domino Knockdown!

A touch-friendly domino chain builder inspired by Mia’s idea: plain ivory dominoes in a twisty path.

- Tap **Push!** or the board to tumble the chain.
- Choose **Draw a path** and draw with a finger. Lift and draw again to add more lines without erasing the earlier ones. **Push!** starts each line together.
- **Undo line** removes the latest line; **Clear board** gives you a blank board in drawing mode. Up to 600 dominoes across 60 lines.
- **Stand them up** resets the chain; **New twisty path** loads another example.
- Optional synthesized click sounds start only after a user gesture.

No downloaded assets, account, microphone, or saved drawings. Paths last for the current page session. The chain uses a timed animation along the drawn path, rather than a collision physics simulation.

Uses the shared Arcade navigation and aggregate analytics scripts.
